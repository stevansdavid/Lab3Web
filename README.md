## Praktikum 3 - CSS Dasar

### 1. Membuat Dokumen HTML

Pada langkah pertama, dibuat dokumen HTML dasar dengan nama `lab2_css_dasar.html`. Dokumen berisi struktur dasar HTML, header, navigasi, dan konten yang akan digunakan untuk praktikum CSS.

### 2. Mendeklarasikan CSS Internal

Pada langkah kedua, ditambahkan CSS Internal menggunakan tag `<style>` pada bagian `<head>`. CSS digunakan untuk mengatur font, header, ukuran, warna, dan posisi heading pada halaman.

![Screenshot 2026-10-07 084130.png](./screenshot/Screenshot%202026-10-07%20084130.png)

### 3. Menambahkan Inline CSS

Pada langkah ketiga, ditambahkan Inline CSS secara langsung pada elemen `<p>`. CSS digunakan untuk mengatur posisi teks dan warna tulisan pada paragraf.

![Screenshot 2026-10-07 084259.png](./screenshot/Screenshot%202026-10-07%20084259.png)

### 4. Membuat CSS Eksternal

Pada langkah keempat, dibuat file `style_eksternal.css` sebagai file CSS terpisah. File tersebut kemudian dihubungkan ke dokumen HTML menggunakan tag `<link>`.

![Screenshot 2026-10-07 084527.png](./screenshot/Screenshot%202026-10-07%20084527.png)

### 5. Menambahkan CSS Selector

Pada langkah kelima, ditambahkan CSS Selector menggunakan ID Selector dan Class Selector. ID Selector digunakan untuk mengatur bagian `intro`, sedangkan Class Selector digunakan untuk mengatur tampilan tombol.
